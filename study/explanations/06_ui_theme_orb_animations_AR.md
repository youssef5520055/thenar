```css
/* مقتطف من رموز ألوان Lagoon الأساسية */
:root {
  --sol-primary: #1aa59a;      /* لون الفيروزي الأساسي المميز */
```

### 2. فيزياء كرة النقاط ثلاثية الأبعاد (3D Stipple Orb)
العنصر البصري الأكثر تميزاً في أعلى الصفحة هو **كرة الـ Orb المنقطة** في ملف `src/components/StippleOrb.tsx`.
الكرة مبنية بالكامل بحسابات الرياضيات المجسمة على وسم `<canvas>` بمعدل 60 إطاراً في الثانية دون الحاجة لمكتبات ثقيلة مثل Three.js:

```typescript
// src/components/StippleOrb.tsx (Verified 3D Projection Snippet)
const points: Point3D[] = [];
const N = 450;
const goldenRatio = (1 + Math.sqrt(5)) / 2;
for (let i = 0; i < N; i++) {
  const theta = 2 * Math.PI * i / goldenRatio;
  const phi = Math.acos(1 - 2 * (i + 0.5) / N);
  const x = Math.cos(theta) * Math.sin(phi);
  const y = Math.sin(theta) * Math.sin(phi);
  const z = Math.cos(phi);
  points.push({ x, y, z });
}
```

#### كيف تعمل معادلات الكرة؟
1. **خوارزمية فيبوناتشي الكروية (Fibonacci Sphere Algorithm):** توزع 450 نقطة بشكل متساوٍ ومثالي هندسياً على سطح الكرة الثلاثية الأبعاد لمنع تجمع النقاط عند القطبين.
2. **الإسقاط المنظوري (Perspective Projection):** تُضرب إحداثيات كل نقطة في معامل العمق البؤري:
   $$x' = x \cdot \frac{d}{z + d}, \quad y' = y \cdot \frac{d}{z + d}$$
3. **التظليل والعمق (Depth Shading):** النقاط الأقرب لعين المشاهد ($z > 0$) تُرسم بحجم أكبر وشفافية كاملة ($\alpha = 1.0$)، بينما النقاط في الجانب الخلفي للكرة تصبح أصغر وبشفافية خافتة ($\alpha = 0.2$)، مما يمنح إيحاءً مبهراً بالعمق الحجمي.
4. **القصور الذاتي والتفاعل (Inertia Damping & Drag):** عند سحب الكرة بالفأرة أو باللمس على شاشة الموبايل، تكتسب سرعة دورانية وتستمر في الدوران مع تباطؤ تدريجي ناعم يحاكي قوانين الاحتكاك الفيزيائي الحقيقي.
5. **مراعاة تقليل الحركة (Reduced Motion):** إذا كان المستخدم مفعلاً لخيار تقليل الحركة في جهازه، تتوقف الدوران التلقائي وتثبت الكرة في وضع هادئ.

### 3. فيزياء الحركة بالنوابض الحقيقية (Framer Motion Springs)
جميع التفاعلات وانتقالات الكروت تتبع حركات نوابض فيزيائية حقيقية (Spring Transitions) بدلاً من منحنيات التوقيت الميكانيكية الجافة (`ease-in-out`):
- **للتفاعلات الدقيقة (Micro-interactions):** صلابة `stiffness: 260` ومخمد `damping: 20` لتعطي ارتداداً حيوياً ملموساً.
- **لانتقال الصفحات واللوحات (Layout Transitions):** صلابة `stiffness: 120` ومخمد `damping: 14` لانتقال ناعم ومريح للعين.
