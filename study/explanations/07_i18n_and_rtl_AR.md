# الفصل السابع: دعم اللغتين وتصميم الواجهة المعكوسة (i18n & RTL)
## Chapter 07: Bilingual Dictionary System & RTL Layout Mirroring

مشروع Thenar مجهز بالكامل ليعمل بلغتين: **الإنجليزية (EN)** و**العربية (AR)** بنقرة زر واحدة في شريط العنوان، مع انعكاس هندسي كامل للواجهة (Full RTL Mirroring) دون أي تشوه بصري أو تداخل في العناصر.

---

### 1. نظام القواميس ثنائية اللغة بدون مكتبات ثقيلة
بدلاً من تحميل حزم ترجمة ضخمة تزيد من حجم التطبيق، تم بناء نظام ترجمة خفيف وسريع يعتمد على ملفي JSON:
- `src/i18n/en.json`: القاموس الإنجليزي.
- `src/i18n/ar.json`: القاموس العربي المكتوب بلغة تقنية دقيقة وواضحة.

```typescript
// src/i18n/index.ts (Verified Translation Hook Snippet)
export function useTranslation() {
  const language = useThenarStore((s) => s.language);
  const t = (key: TranslationKey): string => {
    const dict = language === 'ar' ? arDict : enDict;
    return dict[key] || enDict[key] || key;
  };
  return { t, language };
}
```

#### مميزات هذا التصميم:
- استدعاء فوري بدون أي تأخير زمني.
- خاصية الأمان البديل (Fallback): إذا فُقد أي مفتاح في الترجمة العربية، يعرض النظام النص الإنجليزي المقابل تلقائياً ولا تظهر أي شاشة بيضاء أو خطأ برمجي.

---

### 2. الانعكاس الكامل للواجهة (Full RTL Mirroring)
بمجرد اختيار اللغة العربية:
1. يتم ضبط السمتين فوراً على عنصر الجذر:
   ```javascript
   document.documentElement.dir = 'rtl';
   document.documentElement.lang = 'ar';
   ```
2. القائمة الجانبية (Sidebar) تنتقل تلقائياً من أقصى اليسار إلى أقصى اليمين.
3. الأيقونات ذات الدلالة الاتجاهية (مثل أسهم التنقل ومؤشرات الرجوع للخلف) تنعكس تلقائياً بزاوية 180 درجة باستخدام كلاسات Tailwind الشرطية (`rtl:rotate-180`).
4. يتم تفعيل خط **Cairo** المتميز للأحرف العربية ليعطي شكلاً حديثاً ومريحاً للقراءة.

---

### 3. استثناءات هندسية تظل دائماً من اليسار لليمين (Strict LTR Exceptions)
رغم تعريب كامل الواجهة، هناك قواعد هندسية ومعايير دولية تم الحفاظ عليها بدقة من اليسار لليمين حتى في الواجهة العربية:

1. **محاور الرسوم البيانية (Charts LTR Axes):**
   - محور الزمن في مخططات الإشارة الحركية (Live Telemetry Oscilloscope) يتدفق دائماً من اليسار إلى اليمين ($0.0\text{s} \to 2.5\text{s}$). عكس محور الزمن من اليمين لليسار كان سيسبب إرباكاً للمهندس أو الباحث أثناء قراءة تدفق الإشارة.
2. **الأرقام الإنجليزية/الغربية (Western Numerals):**
   - الأرقام تظل دائماً مكتوبة بالصيغة الغربية (0, 1, 2, 3...) في كلا اللغتين (مثلاً: `24.5 N` و `180 °/s`) لأنها المعيار المعتمد في كافة الأجهزة المعملية وشاشات القياس الهندسية.
3. **الرموز والمتغيرات الرياضية (Mathematical Notation):**
   - الرموز الرياضية مثل سكور السلوك $s(x)$، وعتبة القرار $\tau$، والوحدات الفيزيائية ($N$, $deg/s$, $ms$) تظل بحروفها اللاتينية الأصلية لضمان الدقة الأكاديمية.
